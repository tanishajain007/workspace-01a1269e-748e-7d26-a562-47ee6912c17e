Settings

Your key stays in this browser (and is sent only to generativelanguage.googleapis.com, or to the local Node proxy if you enable it). Put the key in .env as GEMINI_API_KEY=... — the app reads it automatically when served over http://.

Opened via file://? Browsers block reading local files. Either run the included server (node server.mjs) or paste the key below — it is stored in localStorage.

Filters are probabilistic: a SAFETY finish reason can still appear with relaxed thresholds, and blocking can never be fully disabled. Handle it in the UI rather than assuming every request returns text.

Privacy: on the free tier Google states that submitted content may be used to improve its products. Do not paste secrets, customer data, or personal information into a free-tier chatbot.

Google does not publish a single free-tier number — your real RPM / TPM / RPD are per project and visible at aistudio.google.com/rate-limit. Put those numbers (minus a margin) here. RPD resets at midnight Pacific.
